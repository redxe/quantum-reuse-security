# v0.6.0 - Reproducible Stage-1 Baseline

This release establishes a reproducible software baseline for branch-conditioned analysis of known-state qubit reuse under a source-access threat model.

## Highlights

- Reconciled repository metadata and project layout with the actual implementation state.
- Added a modular package surface under src/quantum_reuse with CLI support.
- Added deterministic analysis command:
  - python -m quantum_reuse analyze --output <dir>
- Added fixed-input theorem summary command.
- Added CI matrix testing (Python 3.9, 3.11, 3.13) plus deterministic CSV regression checks.
- Added formalized docs and citation metadata.

## Scientific Scope of This Release

Implemented and validated:

- Deterministic branch-conditioned NumPy reference backend.
- Fixed-input fifth-wire theorem checks for branch outcomes.
- Victim-subsystem preservation checks in the reconstructed branch model.
- Density-matrix numerical validation checks across computed states.

Intentionally unresolved in this release:

- Exact detector-register acceptance condition from the original educational circuit (current rule is explicitly provisional).
- Full Qiskit parity implementation with branch-level equivalence tests.
- Hardware/noise-model validation and malicious compiler prototype.

## Coherent Cleanup Status

The repository now distinguishes between:

- coherent_teleportation_cleanup_quirk(...): reconstructed Quirk-sequence coherent cleanup helper.
- alternate_coherent_cleanup(...): alternate coherent variant retained for restricted-subspace comparison.
- swap_state_transfer_reference(...): direct SWAP transfer reference.

Current tests verify restricted-subspace equivalence on |psi,0,0> inputs and do not claim global unitary equivalence outside that subspace.
